What is CloudShot?

CloudShot is a modern, powerful, and lightweight screenshot application for Windows. It runs in the system tray and is triggered with PrintScreen or the tray icon.

Select any region of the screen, annotate your capture, copy it to the clipboard, save it as a file, extract text with OCR, or upload it to a remote server via SCP.

Main features

  • Region capture with drawing and annotation tools
  • Move and resize the selection before exporting
  • Color picker with zoom preview (RGB, HEX, HSL)
  • Text recognition (OCR) with clipboard copy
  • Automatic upload via SCP with customizable settings
  • Configurable keyboard shortcuts and start with Windows

Keyboard shortcuts

  • PrintScreen — Start capture
  • Ctrl+C — Copy to clipboard
  • Ctrl+S — Save as file
  • Ctrl+Z — Undo last action
  • Ctrl+R — Extract text (OCR)
  • Ctrl+X — Upload via SCP
  • Ctrl+V — Activate color picker
  • Esc — Cancel

All overlay shortcuts can be customized in Settings.
